sirf education; Tier 5 optional. Ankush/manager list ko prune-extend kar sakte

## Coverage rules
- Applicable set: Tier 1+2 (25) + client ke type ka tier (medical +8 / education +5).
- Coverage % per client = SUCCESS listings on applicable dirs / applicable total.
- Report per client in run summary + QA Run Log Notes.
- Missing Tier-1 directories sabse pehle Skill D (backlink-assembly-line) ki
  queue mein suggest karo — wahi asli ~19% Maps-visibility wala impact hai.
- NAP har jagah registry (GBP-matched) wala hi jaye — koi variation nahi.
